Built for Absolute Privacy

No accounts, no email requirements, and zero traces on disk.

🔐

Military-Grade E2EE

Messages are encrypted and authenticated locally with AES-256-GCM. Keys are derived from your room passphrase via SHA-256 and never touch the network.

👁️‍🗨️

Zero-Knowledge Architecture

The relay server is blind. It only sees a truncated one-way hash of the room key and blindly forwards raw ciphertexts without reading usernames or messages.

🛡️

Stealth Traffic (UDP 443)

Chat packets run over Port 443, perfectly mimicking standard HTTP/3 (QUIC) web traffic to defeat strict corporate firewalls and ISP inspection.

⚡

NAT Hole Punching & Keep-Alive

Includes background UDP heartbeat pings every 20 seconds, ensuring your router's NAT hole stays open without dropping packets during quiet spells.

🧼

100% Ephemeral Memory

Nothing is ever written to disk or databases. When you press Ctrl+C, encryption keys and message history vanish permanently from RAM.

🐳

One-Command Docker Relay

Use the official zero-knowledge relay, or spin up your own private forwarder with a single docker run command in seconds.

Self-Hosting & VPS Setup

Deploy your own private Zero-Knowledge relay on any Cloud VPS or home server in 2 minutes.

STEP 1

Prepare Your Server (Firewall & DNS)

IPChat traffic operates over UDP Port 443 (HTTP/3 QUIC disguise). Open this port in your VPS firewall and point an A record (e.g. relay.yourdomain.com) to your server's IP address:

sudo ufw allow 443/udp
STEP 2

Deploy the Relay Server

Choose your preferred deployment method:

Option A: Docker (One-Command Run)

docker run -d --name ipchat-relay --restart unless-stopped -p 443:443/udp ghcr.io/mahamudul-dev/ipchat-relay:latest

Option B: Docker Compose

Create a docker-compose.yml file:

services:
  ipchat-relay:
    image: ghcr.io/mahamudul-dev/ipchat-relay:latest
    container_name: ipchat-relay
    restart: unless-stopped
    ports:
      - "443:443/udp"
    environment:
      - PORT=443
docker compose up -d

Option C: Bare Metal (Linux VPS without Docker)

git clone https://github.com/Mahamudul-Dev/ipchat.git && cd ipchat && dart compile exe bin/relay.dart -o relay && nohup ./relay > relay.log 2>&1 &
STEP 3

Connect Client to Your Self-Hosted Server

Tell your client to persistently use your custom relay (saved to ~/.config/ipchat/config.json):

Permanently register server:
ipchat set-relay relay.yourdomain.com
Check active configured server:
ipchat get-relay
Reset back to official default relay:
ipchat reset-relay
One-time session override without saving:
ipchat --relay relay.yourdomain.com --port 443
